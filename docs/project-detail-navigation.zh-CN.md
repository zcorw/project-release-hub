## 实现决策

以下是既有 React 应用内的实现默认值，在代码修改前记录：

- 项目详情采用 `?project=<id>`。已有工作空间视图采用 `?view=pending` 和 `?view=history`，使浏览器前进、后退恢复对应视图；总览不携带这两个参数。保留其他查询参数与片段，不增加路由依赖或修改服务端端点。
- URL 与页面导航采用同一状态；仅显式导航写入浏览器历史，`popstate` 负责读取历史。打开项目时重置记录标签、临时筛选与对话框。
- 深链接在登录后继续恢复。仅在成功取得已认证快照后判断项目不存在，不将加载中或失败的空快照视为不存在。刷新失败保留目标 URL 并允许重试。项目经确认删除后显示同样的不存在状态。
- 简介和说明均按文本呈现。完整说明使用原生可访问的折叠组件，以所选项目为键，使新一次进入默认收起。同一项目的数据刷新不必关闭用户已展开的说明。简介和说明为空时提供明确占位提示。
- 共享校验、持久化、现有手动确认、审计及首页卡片规则保持既有语义；无需迁移。
