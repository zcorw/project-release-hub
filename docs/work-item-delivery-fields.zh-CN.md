# 任务和问题的交付状态

[English](work-item-delivery-fields.md)

所有项目的任务和问题新增两个独立基础字段：开发验证状态（待核实、未开发、未验证、已验证）和 GitHub 提交状态（待核实、未提交、已提交）。原生命周期状态保持不变。已提交指已经推送到 GitHub，不代表本地提交、合并或部署；在说明中记录提交/PR 链接及验证范围、结果。

历史记录及未提供字段的 API 新增记录保持待核实，不根据完成状态猜测。手动新建默认未开发、未提交。旧客户端修改时省略字段会保留当前值。任务和问题的表单、列表和筛选均支持两个字段。升级前备份数据库，数据库版本升级到 v3 后旧应用会拒绝打开。

验证：2026-11-17 完整检查通过，包括格式、TypeScript、159 项单元/集成测试及生产构建。15 项 Chrome 浏览器测试通过。新字段浏览器用例使用模拟接口；原有浏览器套件验证本地真实 API 流程。未操作生产数据库或部署。用户随后授权提交、推送和创建拉取请求；合并与部署仍不在本次范围内。
